Identity

White-label Odoo 20 — brand, texts, links and a full redesigned app icon set

Replaces every visible vendor element with your own identity: page titles, favicon and PWA metadata, login and portal footers, e-mail footers, user-menu links, the Settings "About" block, the chat bot, every "Odoo" in client and server texts, and all application icons (Community + Enterprise) with a consistent, category-coloured tile set.

Configure it under Settings → Identity. Uninstalling restores the stock look.

The icon design sheet ships with the module: static/description/icons.html.
